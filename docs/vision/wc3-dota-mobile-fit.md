# WC3 / DOTA2 自定义图 → 手游适配调研(阶段 0)

## 约束(用户种子)

竖屏 / 触屏 / 单局短 / **不吃精细微操**。

## 选定

**Green TD / Element TD 系「路径塔防」→ 手游化作品名《晶核防线》。**

可选掺一点 Legion TD 的「构筑一条线」叙事,但**不做**多玩家 lane 对抗(匹配与平衡超出 example 范围)。

## 一句结论(交付验收 ④)

**Green TD / Element TD 系塔防最适合迁移进手游:单指点格子即完成全部操作、波次天然切成 5–8 分钟短局、竖屏「上进下核」路径几乎零改造,且决策在构筑不在微操——与 Warlock/Pudge/MOBA 等吃瞄准与走位的图形成对照。**
