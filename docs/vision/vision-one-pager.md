# 愿景一页纸 · 晶核防线 (Crystal Line)

> 阶段 0 交付物。写完能回答最后一节「再玩一次的理由」再往下走。放 `docs/vision/`。

## X-statement(一句话)

它是 **魔兽争霸 3 自定义图里的 Green TD / Element TD 系塔防**,但 **做成竖屏单指点格子、一局 5–8 分钟、完全不吃微操的手游回合防线**。

## 头 30 秒

- 玩家做什么: 屏幕底栏有 2–3 种「召唤」按钮(不同颜色/费用的塔);点选后点路径旁的格子,落下第一座塔;看第一波小怪从上往下冲,被塔打掉;金币跳字,准备下一格。
- 看到什么: 竖屏深靛色战场;中央一条浅色「裂隙路径」;顶部血红晶核(要护住的东西);底部半透明操作栏;塔是圆润几何色块(强调色鲜明,一眼分得出火/冰/金)。
- **该感到什么**(情绪词): **「有把握的紧张」→ 落下塔的「笃定」→ 清波后的「松一口气」**;不是手忙脚乱的操作焦虑,是**资源与站位的小棋感**。

## 核心瞬间(整个游戏最该好玩的那一个交互)

> 下一阶段的手感切片只做这一个。

**「敌潮已入场、格子还空着 → 手指点下一座塔 → 清脆召唤音 + 塔亮起 → 路径上的怪被打掉 → 晶核安然 + 金币叮」**

整局乐趣都从这一个「放对了/放晚了」的瞬间长出来。切片只验证:点放 → 反馈 → 清波,节奏是否像上面那句话。

## 反例(不要变成什么)

- **不要** 变成需要走位/放技能/接技能的 MOBA 或 Warlock/Pudge Wars(精细瞄准不适合单指通勤)。
- **不要** 变成 Island Troll 式生存建造沙盒(局时长、系统过重)。
- **不要** 变成纯数值放置(没有「格子/路径」空间决策就丢掉 TD 灵魂)。
- **不要** 变成 20 种塔百科全书(切片与首版只保留 2–3 种,辨识度优先)。
- **不要** 横屏键鼠操作感(镜头拖拽、框选多单位一律不做)。

## 再玩一次的理由(回答不出 = 愿景还不成立,别往下)

「上一局差一格就破核 / 差一种塔就漏怪——**我想换一套站位再试一波**。」短失败成本 + 构筑可读 + 下一局立刻能验证假设 = 再开一局的钩子。不是剧情,不是抽卡,是**小棋复盘欲**。
