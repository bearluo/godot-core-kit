# 愿景一页纸 · 晶核防线 (Crystal Line)

> 阶段 0 交付物。写完能回答最后一节「再玩一次的理由」再往下走。放 `docs/vision/`。
> 种子调研见同目录 `wc3-dota-mobile-fit.md`。

## X-statement(一句话)

它是 **魔兽争霸 3 自定义图里的 Green TD / Element TD 系塔防**,但 **做成竖屏单指点格子、一局 5–8 分钟、完全不吃微操的手游回合防线**。

## 头 30 秒

- 玩家做什么: 屏幕底栏有 2–3 种「召唤」按钮(不同颜色/费用的塔);点选后点路径旁的格子,落下第一座塔;看第一波小怪从上往下冲,被塔打掉;金币跳字,准备下一格。
- 看到什么: 竖屏深靛色战场;一条浅色「裂隙路径」从**顶部裂口蜿蜒折返而下**(不是一条直线);**底部血红晶核**(要护住的东西,在路径终点);底部半透明操作栏;塔是圆润几何色块(强调色鲜明,一眼分得出火/冰/金)。
- **该感到什么**(情绪词): **「有把握的紧张」→ 落下塔的「笃定」→ 清波后的「松一口气」**;不是手忙脚乱的操作焦虑,是**资源与站位的小棋感**。

## 核心瞬间(整个游戏最该好玩的那一个交互)

> 下一阶段的手感切片只做这一个。

**「敌潮已入场、格子还空着 → 手指点下一座塔 → 清脆召唤音 + 塔亮起 → 路径上的怪被打掉 → 晶核安然 + 金币叮」**

整局乐趣都从这一个「放对了/放晚了」的瞬间长出来。切片只验证:点放 → 反馈 → 清波,节奏是否像上面那句话。

## 情绪板

文字情绪板: [`refs/moodboard-notes.md`](refs/moodboard-notes.md)。本 example 不落盘第三方游戏截图
(要提交进仓库、要公开分发,版权不清),用文字锚定「在追什么」——每条写清哪个作品的哪一点 + 我追它的什么。

- **Green TD / Element TD** — 追 **路径清晰 + 格子决策** 的 TD 骨架。
- **Legion TD(建造侧)** — 追 **「我在构筑一条线」** 的成长感,不是无脑铺满。
- **现代手游竖屏 TD HUD** — 追 **竖屏上路径纵向、操作区贴拇指** 的布局。
- 配色: 背景 `#1a1f3a` 深靛;路径 `#3d4a6b`;晶核 `#e74c5e` 危险红;火塔 `#e67e22` / 冰塔 `#4fc3f7` / 金塔 `#f1c40f`;UI 字 `#ecf0f1`。
- 形状语言: **圆角几何、大色块、少描边**——像「可触的棋子」,不是写实魔兽模型;塔=圆盘底座+中心符号,怪=朝下的三角/菱形。
- 节奏基调: **波间松、波内紧**——放塔决策给 2–4 秒喘息,怪入场后 8–15 秒持续输出感;整局 5–8 分钟,不马拉松。

## 反例(不要变成什么)

- **不要** 变成需要走位/放技能/接技能的 MOBA 或 Warlock/Pudge Wars(精细瞄准不适合单指通勤)。
- **不要** 变成 Island Troll 式生存建造沙盒(局时长、系统过重)。
- **不要** 变成纯数值放置(没有「格子/路径」空间决策就丢掉 TD 灵魂)。
- **不要** 变成 20 种塔百科全书(切片与首版只保留 2–3 种,辨识度优先)。
- **不要** 横屏键鼠操作感(镜头拖拽、框选多单位一律不做)。

## 一局的形状(R1 补写)

一局 = **14 波**。波与波之间有 5–8 秒备战窗口(第一波前 8 秒),倒计时归零自动开波,玩家也可以点「立即开波」抢时间。
**清完 14 波 = 胜利;晶核 10 点血扣光 = 失败。** 胜负都进结算(波次 / 击杀 / 漏怪 / 用时 / 历史最好),结算上唯一的按钮是「再来一局」。

## 再玩一次的理由(回答不出 = 愿景还不成立,别往下)

「上一局差一格就破核 / 差一种塔就漏怪——**我想换一套站位再试一波**。」短失败成本 + 构筑可读 + 下一局立刻能验证假设 = 再开一局的钩子。不是剧情,不是抽卡,是**小棋复盘欲**。

## 愿景演进记录

> vision-first 的规矩:实现与一页纸打架时,**先改这里、说清为什么,再动代码**。悄悄漂移不算数。

### 2026-07-27 · 晶核从「顶部」改为「底部」(R1 / CL-008)

- **改了什么**: 上面「看到什么」一节原文是「**顶部**血红晶核」,现改为「**底部**血红晶核(在路径终点)」。
- **为什么**: 同一段还写着「看第一波小怪**从上往下冲**」。怪从顶部入场、却要保护顶部的东西,方向自相矛盾;
  竖屏手游的通行读法是**敌人自上而下推进、己方基地在下方靠近拇指**,这样「防线越来越靠近我」的压迫感才成立。
  两句里错的是「顶部晶核」这一句,不是实现。
- **代价 / 放弃了什么**: 放弃「一眼看到要守的东西在视线最上方」的构图;改由**晶核血环 + 顶部 HUD 的「晶核 N」**承担同一职责。
- **不改的**: 敌人仍从顶部裂口入场,路径仍纵向推进,单指点格操作不变。

### 2026-07-27 · 路径从「中央直线一列」改为「蜿蜒折返」(R1 / CL-005)

- **改了什么**: 「中央一条浅色裂隙路径」→「从顶部裂口**蜿蜒折返而下**」。
- **为什么**: 直线单列时,所有可建造格到路径的横向距离恒为 1,「放哪一格」退化成「放第几行」,
  一页纸点名的「资源与**站位**的小棋感」少了站位那一半,也丢掉了 Green TD / Element TD 的灵魂(一座塔覆盖多段)。
- **代价**: 可建造格从 32 个减到 20 个,棋盘更拥挤;右上角出现几乎覆盖不到路径的「死格」——
  用备战阶段的**站位亮点提示**(亮点越大 = 该格覆盖路径越长)把这个代价变成可读的信息,而不是暗坑。
