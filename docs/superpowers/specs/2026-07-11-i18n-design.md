# i18n 本地化托管层设计(LocaleManager / `CoreKit.i18n`)

> 阶段4 补缺库 2/4。对标 Godot 原生 `TranslationServer`/`tr()` 的托管封装:运行时切语言 + 持久化 + 字体回退 + 缺翻译告警 + 运行时翻译加载。

**版本:** v0.10.0(承 DevConsole v0.9.0)

## 目标

给使用 core-kit 的游戏一个**单点托管的本地化层**:一行 `CoreKit.i18n.set_locale("zh")` 完成「切换 TranslationServer 语言 + 持久化到 Settings + 按 locale 换 Theme 字体 + 发 `locale_changed` 信号」;`CoreKit.i18n.t("MENU_START")` 在缺翻译时(debug 构建)去重告警,帮开发期发现漏翻。Godot 原生 API(`tr()`/`TranslationServer`)照旧可用,本层是**增值托管**而非替代。

## 非目标(YAGNI v1)

- **复数形式**(`translate_plural`):v1 不做,注明为后续可加。
- **母语显示名**(native display name):v1 用引擎英文名 `TranslationServer.get_locale_name()`;母语名需自维护表,暂缓。
- **动态字体全局副作用**:不改 `ThemeDB.fallback_font` 之类全局默认,只换**显式绑定的 Theme**的 `default_font`,副作用可控、可回退。
- **翻译文件的编辑期导入**:`.po`/`.csv` → `.translation` 是 Godot 编辑器导入职责;本层只在运行时 `load()` 已存在的 `.translation`/`.tres` 资源。

## 架构 / 接入

新子系统 `CoreKit.i18n`,脚本 `addons/godot-core-kit/systems/locale_manager.gd`(`extends Node`,归 `systems/`,与 audio/input 同为依赖 Settings 的 business 子系统)。

- **门面接线**(`core_kit.gd`):
  - `_init` 中作**第 12 个子系统**构造:`i18n = LocaleManagerScript.new(); i18n.name = "LocaleManager"; add_child(i18n)`(排在 `console` 之后)。
  - `_ready` 中 `i18n.bind_settings(settings)`(settings 已在第 2 位构造,注入安全)。
  - `_services["i18n"] = i18n` 预注册;`RESERVED_KEYS += "i18n"`;`VERSION → "0.10.0"`。
- **属性名 `i18n`**:域内通用词(roadmap/记忆均用它)。GDScript 允许 `i18n` 作标识符,`CoreKit.i18n` 合法。
- **持久化范式**(照 audio/input):`const SETTINGS_SECTION := "locale"`;`var _settings = null`(untyped,未注入为 null,脱离门面可独立单测);`bind_settings(settings)` 注入时读回 `get_value("locale", "current")` 并应用;`set_locale` 时 `_settings.set_value("locale", "current", locale)` 落盘。

### 内部结构

`locale_manager.gd` 单文件即可(职责聚焦:一个 TranslationServer 的托管包装 + 三张小表)。内部持有:

| 字段 | 类型 | 说明 |
|---|---|---|
| `_settings` | untyped(=null) | 注入的 Settings;null 时不持久化 |
| `_theme` | `Theme`(=null) | `bind_theme` 绑定的托管 Theme;换 locale 时改其 `default_font` |
| `_locale_fonts` | `Dictionary`(locale→Font) | `register_locale_font` 注册表 |
| `_warned` | `Dictionary`(`"locale|key"`→true) | 缺翻译告警去重集 |

不额外拆 RefCounted 子单元——本子系统逻辑量小且强依赖全局 `TranslationServer`(拆分不产生可独立测试的纯逻辑收益,与 DevConsole 的 registry/evaluator/watch 情形不同)。

## 公共 API

### 核心切换

| 成员 | 说明 |
|---|---|
| `set_locale(locale: String) -> void` | 空串 → `push_warning` no-op;与当前 `TranslationServer.get_locale()` 相同 → no-op(不重复落盘/发信号);否则 `TranslationServer.set_locale(locale)` → 持久化 → 应用字体 → `emit locale_changed(locale)`。 |
| `get_locale() -> String` | `TranslationServer.get_locale()`。 |
| `available_locales() -> PackedStringArray` | `TranslationServer.get_loaded_locales()`(有已加载翻译的 locale)。 |
| `locale_display_name(locale: String) -> String` | `TranslationServer.get_locale_name(locale)`(英文名,如 "English"/"Chinese")。 |
| `signal locale_changed(locale: String)` | 每次成功切换后**始终**发射(未用 bind_theme 的游戏靠此 + `font_for_locale` 自换字体)。 |

### 翻译访问 + 缺翻译告警

| 成员 | 说明 |
|---|---|
| `t(key: StringName, context: String = "") -> String` | 托管 tr:`TranslationServer.translate(key, context)`;若结果 == key(缺失)且 `OS.is_debug_build()`,按 `"locale|key"` 去重后 `push_warning`(每键每语言仅一次);返回译文(或原 key)。**不经 `CoreKit.log`**——保 LocaleManager 零门面耦合、可脱离门面独立单测(同 `_settings=null` 意图)。 |
| `has_translation(key: StringName, context: String = "") -> bool` | 当前 locale 下 `translate(key) != key`。 |

### 字体回退

| 成员 | 说明 |
|---|---|
| `register_locale_font(locale: String, font: Font) -> void` | 存入 `_locale_fonts`;`font == null` → `push_warning` 忽略。 |
| `font_for_locale(locale: String) -> Font` | 取注册字体,无 → null。 |
| `bind_theme(theme: Theme) -> void` | 持有托管 Theme(null 清除);绑定时若当前 locale 已注册字体,立即应用一次。 |

### 运行时翻译加载

| 成员 | 说明 |
|---|---|
| `add_translation(translation: Translation) -> void` | 薄包 `TranslationServer.add_translation`;null → `push_warning` 忽略。 |
| `load_translation(path: String) -> bool` | `ResourceLoader.load(path)`,校验 `is Translation` → `add_translation` → true;失败(加载不到 / 非 Translation)→ `push_warning` + false。 |
| `load_translations(dir: String) -> int` | 扫 `dir` 下 `*.translation` 与 `*.tres`,逐个 `load_translation`,返回成功数;目录打不开 → `push_warning` + 0。 |

### 门面接线

| 成员 | 说明 |
|---|---|
| `bind_settings(settings) -> void` | 存 `_settings`;读 `settings.get_value("locale", "current")`,若为非空 String 则应用(等价 `set_locale`,含落盘幂等)。 |

## 数据流

**启动恢复**:`CoreKit._ready` → `i18n.bind_settings(settings)` → 若上次持久化过 locale,读回并 `TranslationServer.set_locale` + 应用字体 + 发信号。无持久化则保持 Godot 默认(项目/OS locale)。

**运行时切换**:游戏调 `CoreKit.i18n.set_locale("zh")` → 去重检查 → `TranslationServer.set_locale("zh")`(引擎向所有节点发 `NOTIFICATION_TRANSLATION_CHANGED`,`tr()` 文本自动刷新)→ `_settings.set_value` 落盘 → 若 `_theme` 且 zh 有注册字体 → `_theme.default_font = 字体` → `emit locale_changed("zh")`。

**字体两条路**:①用 `bind_theme` 的游戏——托管 Theme 的 `default_font` 被自动换,该 Theme 覆盖的 Control 子树立即换字。②不用 bind_theme 的游戏——连 `locale_changed` 自行 `font_for_locale(locale)` 取字体应用到目标节点。

**运行时加载(DLC/追加)**:`load_translation("res://dlc/fr.translation")` → 注册进 TranslationServer → 此后 `available_locales()` 含 fr、`set_locale("fr")` 生效。

## 错误处理

- 空 locale → `push_warning` no-op。
- `load_translation` 坏路径 / 非 Translation → `push_warning` + false(不抛)。
- `register_locale_font(null)` / `add_translation(null)` → `push_warning` 忽略。
- `bind_theme(null)` → 合法,清除托管 Theme(后续切 locale 不动字体)。
- `t()` 缺失 → 去重 `push_warning`(debug-only)+ 返回 key(Godot `translate` 缺失即返回 key)。
- 全部经 `push_warning`;无 `push_error`、无 crash 路径。LocaleManager 不引用 `CoreKit`/`CoreKit.log`(零门面耦合,standalone 可测)。

## 测试(headless,`test/test_locale_manager.gd`)

`extends SceneTree` / `_initialize()`,直接实例化 `LocaleManagerScript`(不经门面)。TranslationServer 全局可用于 headless。

**隔离**:`_initialize` 开头存 `TranslationServer.get_locale()` 原值,teardown 前 `TranslationServer.set_locale(原值)` 恢复(全局单例,虽各 test 独立进程仍稳妥)。

覆盖:

1. **核心切换 + 信号**:代码建两个 `Translation`(en `{GREETING:"Hello"}` / zh `{GREETING:"你好"}`),`add_translation` 两者;连 `locale_changed`;`set_locale("en")` → `t("GREETING")=="Hello"`、`get_locale()=="en"`、信号收到 "en";`set_locale("zh")` → `t("GREETING")=="你好"`。
2. **去重 no-op**:同 locale 再 `set_locale` → 信号计数不增。
3. **缺翻译**:`t("NOPE")=="NOPE"` 且 `has_translation("NOPE")==false`(告警是副作用,不断言日志文本,仅验返回值 + 不 crash)。
4. **available / display**:`available_locales()` 含 en/zh;`locale_display_name("en")=="English"`。
5. **字体**:`register_locale_font("zh", FontFile.new())` + `bind_theme(Theme.new())`;`set_locale("zh")` → `theme.default_font` 为该字体;`set_locale("en")`(en 无注册字体)→ `theme.default_font` 不变(不清)。
6. **运行时加载**:`ResourceSaver.save(tr, "user://__t_locale.tres")` → `load_translation("user://__t_locale.tres")==true` → set_locale + t 生效 → 清理临时文件。
7. **持久化**:真 `Settings`(临时 path,照 test_audio_manager 手法)`bind_settings`;预置 `set_value("locale","current","zh")` 后 `bind_settings` → locale 变 zh;`set_locale("en")` 后 `get_value("locale","current")=="en"`。

通过判据:`test_locale_manager: ALL PASS` + `quit(0)`。
