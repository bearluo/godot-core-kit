# i18n 本地化托管层实现计划(LocaleManager / `CoreKit.i18n`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development(推荐)或 superpowers:executing-plans 逐任务实现本计划。步骤用 checkbox(`- [ ]`)跟踪。

**Goal:** 新增 `CoreKit.i18n`(LocaleManager)作为第 12 个子系统,托管 Godot `TranslationServer`:运行时切语言 + 持久化到 Settings + 按 locale 换绑定 Theme 字体 + 缺翻译 `push_warning` 告警 + 运行时翻译加载。

**Architecture:** 单文件业务子系统 `systems/locale_manager.gd`(`extends Node`),照 audio/input 的 `bind_settings` 持久化范式,section `"locale"`。零门面耦合(缺翻译告警走 `push_warning`,不引用 `CoreKit.log`),故可脱离门面 headless 独立单测。字体只换显式 `bind_theme` 的 `Theme.default_font`,不动任何全局默认(`ThemeDB`)。

**Tech Stack:** Godot 4.7-stable-mono,纯 GDScript。全局单例 `TranslationServer`、`Translation`、`Theme`/`FontFile`、`ResourceSaver`/`ResourceLoader`/`DirAccess`。

## Global Constraints

- **版本 0.10.0**:`plugin.cfg` 与 `CoreKit.VERSION` 同源,统一 `"0.10.0"`。
- **子系统计数 11 → 12**:所有文档/注释/断言里表示"内置子系统数量"的 `11` 改 `12`(`CoreKit.i18n` 为第 12 个)。
- **零门面耦合**:`locale_manager.gd` 不得引用 `CoreKit` / `CoreKit.log`;缺翻译告警与参数校验一律 `push_warning`。(这是本子系统能脱离门面独立单测的前提,与 `_settings=null` 同意图。)
- **持久化范式照 audio/input**:`const SETTINGS_SECTION := "locale"`;`var _settings = null`(untyped);`bind_settings(settings)` 注入时恢复、`set_locale` 时写透;section 键为 `"current"`。

```gdscript
extends Node
## LocaleManager —— i18n 本地化托管层。托管 Godot 全局 TranslationServer:
## 运行时切语言 + 持久化(经 bind_settings 注入的 Settings,section "locale")+
## 按 locale 换绑定 Theme 的字体 + 缺翻译 push_warning 告警 + 运行时翻译加载。
## 经 CoreKit.i18n 访问,是第 12 个子系统。
##
## 零门面耦合:不引用 CoreKit / CoreKit.log(缺翻译告警走 push_warning),故可脱离
## 门面独立实例化 headless 单测(同 _settings=null 意图)。字体不改任何全局默认
## (ThemeDB),只换显式 bind_theme 的 Theme.default_font,副作用可控可回退。
##
## Godot 注:切 locale 时引擎向所有节点发 NOTIFICATION_TRANSLATION_CHANGED,tr()
## 文本自动刷新;本层额外提供托管切换 + 持久化 + 字体 + 信号兜底。

## 每次成功切换 locale 后广播(未用 bind_theme 的游戏靠此 + font_for_locale 自换字体)。
signal locale_changed(locale: String)

const SETTINGS_SECTION := "locale"

## bind_settings 注入;untyped:未注入(脱离门面单测/不持久化)时为 null。
var _settings = null
## bind_theme 绑定的托管 Theme;换 locale 时改其 default_font。未绑定为 null。
var _theme: Theme = null
## locale(String)-> Font 注册表。
var _locale_fonts: Dictionary = {}
## 缺翻译告警去重集,键 "locale|key" -> true(每键每语言仅告警一次)。
var _warned: Dictionary = {}


## 注入 Settings:持有引用并恢复上次持久化的 locale(无则保持引擎默认)。
func bind_settings(settings) -> void:
	_settings = settings
	if _settings == null:
		return
	var stored = _settings.get_value(SETTINGS_SECTION, "current")
	if stored is String and not stored.is_empty():
		set_locale(stored)


## 切换 locale。空串 → 警告 no-op;与当前相同 → no-op(不重复落盘/发信号);否则切
## TranslationServer + 持久化 + 应用字体 + 发 locale_changed。
func set_locale(locale: String) -> void:
	if locale.is_empty():
		push_warning("LocaleManager.set_locale: 空 locale,忽略")
		return
	if TranslationServer.get_locale() == locale:
		return
	TranslationServer.set_locale(locale)
	if _settings != null:
		_settings.set_value(SETTINGS_SECTION, "current", locale)
	_apply_font(locale)
	locale_changed.emit(locale)


func get_locale() -> String:
	return TranslationServer.get_locale()


## 有已加载翻译的 locale 列表。
func available_locales() -> PackedStringArray:
	return TranslationServer.get_loaded_locales()


## locale 的英文显示名(如 "en" -> "English")。
func locale_display_name(locale: String) -> String:
	return TranslationServer.get_locale_name(locale)


## 托管 tr:取当前 locale 译文;缺失(译文 == key)且 debug 构建时按 "locale|key"
## 去重 push_warning(每键每语言仅一次)。返回译文(缺失则原 key)。
func t(key: StringName, context: String = "") -> String:
	var out := String(TranslationServer.translate(key, context))
	if out == String(key) and OS.is_debug_build():
		var mark := "%s|%s" % [TranslationServer.get_locale(), key]
		if not _warned.has(mark):
			_warned[mark] = true
			push_warning("LocaleManager: 缺翻译 [%s] key '%s'" % [TranslationServer.get_locale(), key])
	return out


## 当前 locale 下是否有该 key 的翻译。
func has_translation(key: StringName, context: String = "") -> bool:
	return String(TranslationServer.translate(key, context)) != String(key)


## 注册某 locale 的字体;null 忽略并告警。
func register_locale_font(locale: String, font: Font) -> void:
	if font == null:
		push_warning("LocaleManager.register_locale_font: font 为 null,忽略(locale=%s)" % locale)
		return
	_locale_fonts[locale] = font


## 取某 locale 注册的字体,无 → null。
func font_for_locale(locale: String) -> Font:
	return _locale_fonts.get(locale)


## 绑定托管 Theme(null 清除);切 locale 时换其 default_font。绑定时若当前 locale
## 已注册字体,立即应用一次。
func bind_theme(theme: Theme) -> void:
	_theme = theme
	if _theme != null:
		_apply_font(TranslationServer.get_locale())


## 注册一个内存 Translation。null 忽略并告警。
func add_translation(translation: Translation) -> void:
	if translation == null:
		push_warning("LocaleManager.add_translation: translation 为 null,忽略")
		return
	TranslationServer.add_translation(translation)


## 从 path 加载一个 .translation/.tres 翻译资源并注册。成功 true;加载不到 / 非
## Translation → 警告 + false。
func load_translation(path: String) -> bool:
	var loaded = ResourceLoader.load(path)
	if loaded == null or not (loaded is Translation):
		push_warning("LocaleManager.load_translation: '%s' 加载失败或非 Translation" % path)
		return false
	TranslationServer.add_translation(loaded)
	return true


## 扫 dir 下 *.translation 与 *.tres 逐个加载注册,返回成功数。目录打不开 → 警告 + 0。
func load_translations(dir: String) -> int:
	var da := DirAccess.open(dir)
	if da == null:
		push_warning("LocaleManager.load_translations: 无法打开目录 '%s'" % dir)
		return 0
	var count := 0
	da.list_dir_begin()
	var entry := da.get_next()
	while entry != "":
		if not da.current_is_dir() and (entry.ends_with(".translation") or entry.ends_with(".tres")):
			if load_translation(dir.path_join(entry)):
				count += 1
		entry = da.get_next()
	da.list_dir_end()
	return count


## 换绑定 Theme 的 default_font 为该 locale 注册的字体(未绑定 Theme 或该 locale
## 未注册字体则不动)。
func _apply_font(locale: String) -> void:
	if _theme != null and _locale_fonts.has(locale):
		_theme.default_font = _locale_fonts[locale]
```

- [ ] **Step 2: 创建 `test/test_locale_manager.gd`(完整内容)**

```gdscript
extends SceneTree
## LocaleManager headless 断言测试。直接实例化脚本(不经门面),TranslationServer
## 全局单例在 headless 下可用。LocaleManager 无树依赖(无 _ready 逻辑),故 new()
## 后直接调方法,无需 add_child / await。
## 运行:godot --headless --path . -s res://test/test_locale_manager.gd
##
## 加载注:settings.gd 运行期引用全局 autoload 标识符 CoreKit(_save_to_disk 里
## CoreKit.log.error),故不在类作用域 preload,延迟到 _initialize() 内 load()。
## LocaleManager 本身零 CoreKit 引用,一并 load() 保持一致。
##
## 隔离:TranslationServer 是全局单例;开头存原 locale,结尾恢复(各 test 虽独立
## 进程,仍稳妥)。

var LocaleManagerScript
var SettingsScript

const SETTINGS_PATH := "user://__test_locale_settings__.json"
const TMP_TRES := "user://__test_locale.tres"
const TMP_DIR := "user://__test_locale_dir__"


func _initialize() -> void:
	LocaleManagerScript = load("res://addons/godot-core-kit/systems/locale_manager.gd")
	SettingsScript = load("res://addons/godot-core-kit/core/settings.gd")
	var failures := 0
	var original_locale := TranslationServer.get_locale()

	# 预置两语内存翻译
	var en_tr := Translation.new()
	en_tr.locale = "en"
	en_tr.add_message("GREETING", "Hello")
	var zh_tr := Translation.new()
	zh_tr.locale = "zh"
	zh_tr.add_message("GREETING", "你好")

	var lm = LocaleManagerScript.new()
	lm.add_translation(en_tr)
	lm.add_translation(zh_tr)

	# 1. 核心切换 + 信号:建立 en 基线(直改 TS,不经 lm,无信号),lm 切 zh 为真迁移
	var locale_events := []
	lm.locale_changed.connect(func(loc): locale_events.append(loc))
	TranslationServer.set_locale("en")   # 基线,不经 lm
	lm.set_locale("zh")                   # en -> zh 真迁移
	if lm.get_locale() != "zh":
		print("FAIL 1: set_locale('zh') 后 get_locale 应为 zh,实际 %s" % lm.get_locale())
		failures += 1
	if lm.t("GREETING") != "你好":
		print("FAIL 1: zh 下 t(GREETING) 应为 你好,实际 %s" % lm.t("GREETING"))
		failures += 1
	if locale_events != ["zh"]:
		print("FAIL 1: locale_changed 应广播一次 zh,实际 %s" % [locale_events])
		failures += 1
	lm.set_locale("en")                   # zh -> en 真迁移
	if lm.t("GREETING") != "Hello":
		print("FAIL 1: en 下 t(GREETING) 应为 Hello,实际 %s" % lm.t("GREETING"))
		failures += 1

	# 2. 同 locale 去重 no-op + 空串 no-op:不再发信号
	var count_before := locale_events.size()   # 此刻 ["zh","en"]
	lm.set_locale("en")                        # 与当前相同 -> no-op
	if locale_events.size() != count_before:
		print("FAIL 2: 同 locale set_locale 应 no-op 不发信号")
		failures += 1
	lm.set_locale("")                          # 空串 -> 警告 no-op
	if locale_events.size() != count_before:
		print("FAIL 2: 空 locale 应 no-op")
		failures += 1

	# 3. 缺翻译:t 返回 key,has_translation 假(告警是副作用,只验返回值)
	if lm.t("NOPE_KEY") != "NOPE_KEY":
		print("FAIL 3: 缺翻译 t 应返回原 key")
		failures += 1
	if lm.has_translation("NOPE_KEY"):
		print("FAIL 3: 缺翻译 has_translation 应为 false")
		failures += 1
	if not lm.has_translation("GREETING"):
		print("FAIL 3: 已有翻译 has_translation 应为 true")
		failures += 1

	# 4. available / display
	var locs: PackedStringArray = lm.available_locales()
	if not (locs.has("en") and locs.has("zh")):
		print("FAIL 4: available_locales 应含 en/zh,实际 %s" % [locs])
		failures += 1
	if lm.locale_display_name("en") != "English":
		print("FAIL 4: locale_display_name('en') 应为 English,实际 %s" % lm.locale_display_name("en"))
		failures += 1

	# 5. 字体:注册 zh 字体 + bind_theme;切 zh 换 default_font;切无字体 locale 不清
	var zh_font := FontFile.new()
	var theme := Theme.new()
	lm.register_locale_font("zh", zh_font)
	lm.bind_theme(theme)                       # 当前 en 无字体,default_font 保持 null
	if theme.default_font != null:
		print("FAIL 5: bind_theme 时当前 locale(en)无字体,default_font 应为 null")
		failures += 1
	lm.set_locale("zh")                        # en -> zh,zh 有字体
	if theme.default_font != zh_font:
		print("FAIL 5: 切 zh 后 default_font 应为注册字体")
		failures += 1
	lm.set_locale("en")                        # zh -> en,en 无字体 -> 不清
	if theme.default_font != zh_font:
		print("FAIL 5: 切到无字体 locale 应保留旧 default_font(不清)")
		failures += 1
	if lm.font_for_locale("zh") != zh_font:
		print("FAIL 5: font_for_locale('zh') 应返回注册字体")
		failures += 1
	if lm.font_for_locale("fr") != null:
		print("FAIL 5: 未注册 locale font_for_locale 应为 null")
		failures += 1
	lm.register_locale_font("de", null)        # null -> 警告忽略,不崩
	if lm.font_for_locale("de") != null:
		print("FAIL 5: null 字体不应注册")
		failures += 1

	# 6. 运行时加载:save 一个 fr 翻译到 user://,load_translation 注册后可用
	var fr_tr := Translation.new()
	fr_tr.locale = "fr"
	fr_tr.add_message("GREETING", "Bonjour")
	ResourceSaver.save(fr_tr, TMP_TRES)
	if not lm.load_translation(TMP_TRES):
		print("FAIL 6: load_translation 应成功")
		failures += 1
	TranslationServer.set_locale("en")         # 基线
	lm.set_locale("fr")                        # en -> fr
	if lm.t("GREETING") != "Bonjour":
		print("FAIL 6: 加载后 fr 下 t(GREETING) 应为 Bonjour,实际 %s" % lm.t("GREETING"))
		failures += 1
	# 非 Translation 资源 -> false(用一个 .gd 脚本资源,避免不存在路径的引擎 error 噪音)
	if lm.load_translation("res://addons/godot-core-kit/core/log.gd"):
		print("FAIL 6: 非 Translation 资源 load_translation 应返回 false")
		failures += 1
	# load_translations 目录扫描:两个 .tres -> 2
	DirAccess.make_dir_recursive_absolute(TMP_DIR)
	ResourceSaver.save(en_tr, TMP_DIR.path_join("a.tres"))
	ResourceSaver.save(zh_tr, TMP_DIR.path_join("b.tres"))
	var loaded_n: int = lm.load_translations(TMP_DIR)
	if loaded_n != 2:
		print("FAIL 6: load_translations 应加载 2 个,实际 %d" % loaded_n)
		failures += 1

	# 7. 持久化:预置 settings 的 locale/current;bind 时应用;set_locale 后写透
	if FileAccess.file_exists(SETTINGS_PATH):
		DirAccess.remove_absolute(SETTINGS_PATH)
	var settings = SettingsScript.new()
	settings.settings_path = SETTINGS_PATH
	settings.set_value("locale", "current", "zh")   # 预置
	var lm2 = LocaleManagerScript.new()
	TranslationServer.set_locale("en")              # 基线,保证 bind 的 zh 是真迁移
	lm2.bind_settings(settings)                     # 读回 zh 并 set_locale('zh')
	if lm2.get_locale() != "zh":
		print("FAIL 7: bind_settings 应恢复持久化 locale 到 zh,实际 %s" % lm2.get_locale())
		failures += 1
	lm2.set_locale("en")                            # 真迁移,应写透 settings
	if settings.get_value("locale", "current") != "en":
		print("FAIL 7: set_locale 应写透 settings.locale.current,实际 %s" % [settings.get_value("locale", "current")])
		failures += 1

	# 清理
	TranslationServer.set_locale(original_locale)
	lm.free()
	lm2.free()
	settings.free()
	if FileAccess.file_exists(TMP_TRES):
		DirAccess.remove_absolute(TMP_TRES)
	if FileAccess.file_exists(TMP_DIR.path_join("a.tres")):
		DirAccess.remove_absolute(TMP_DIR.path_join("a.tres"))
	if FileAccess.file_exists(TMP_DIR.path_join("b.tres")):
		DirAccess.remove_absolute(TMP_DIR.path_join("b.tres"))
	if DirAccess.dir_exists_absolute(TMP_DIR):
		DirAccess.remove_absolute(TMP_DIR)
	if FileAccess.file_exists(SETTINGS_PATH):
		DirAccess.remove_absolute(SETTINGS_PATH)

	if failures == 0:
		print("test_locale_manager: ALL PASS")
		quit(0)
	else:
		print("test_locale_manager: %d FAILURE(S)" % failures)
		quit(1)
```

```markdown
# i18n 本地化托管层(LocaleManager)

> `CoreKit.i18n` · `systems/locale_manager.gd` · 第 12 个子系统

## 职责

托管 Godot 全局 `TranslationServer`,给游戏一个单点本地化层:运行时切语言、持久化玩家选择、按 locale 换字体、开发期发现漏翻、运行时追加翻译。原生 `tr()` / `TranslationServer` 照旧可用,本层是增值托管而非替代。

## 公开 API

### 语言切换

| 成员 | 说明 |
|---|---|
| `set_locale(locale: String) -> void` | 切语言。空串 → 警告 no-op;与当前相同 → no-op(不重复落盘/发信号);否则切 `TranslationServer` + 持久化 + 换字体 + 发 `locale_changed`。 |
| `get_locale() -> String` | 当前 locale。 |
| `available_locales() -> PackedStringArray` | 有已加载翻译的 locale。 |
| `locale_display_name(locale) -> String` | 引擎英文显示名(如 `"en"` → `"English"`)。 |
| `signal locale_changed(locale: String)` | 每次成功切换后广播。 |

### 翻译访问

| 成员 | 说明 |
|---|---|
| `t(key, context := "") -> String` | 托管 `tr`:取当前 locale 译文;缺失(译文 == key)且 debug 构建时按 `locale\|key` 去重 `push_warning`(每键每语言仅一次)。 |
| `has_translation(key, context := "") -> bool` | 当前 locale 下是否有该 key 的翻译。 |

### 字体回退

| 成员 | 说明 |
|---|---|
| `register_locale_font(locale, font: Font) -> void` | 注册某 locale 的字体(null 忽略)。 |
| `font_for_locale(locale) -> Font` | 取注册字体,无 → null。 |
| `bind_theme(theme: Theme) -> void` | 绑定托管 Theme(null 清除);切 locale 时换其 `default_font`,绑定时若当前 locale 有字体立即应用。 |

### 运行时翻译加载

| 成员 | 说明 |
|---|---|
| `add_translation(translation: Translation) -> void` | 注册一个内存 `Translation`(null 忽略)。 |
| `load_translation(path) -> bool` | 加载一个 `.translation`/`.tres` 并注册;失败 → 警告 + false。 |
| `load_translations(dir) -> int` | 扫目录下 `*.translation`/`*.tres` 逐个加载,返回成功数。 |

### 门面接线

| 成员 | 说明 |
|---|---|
| `bind_settings(settings) -> void` | 门面在 `_ready` 注入;恢复上次持久化的 locale(section `"locale"`,键 `"current"`),`set_locale` 时写透。 |

## 依赖

- 单向依赖注入的 `Settings`(经 `bind_settings`,持久化 locale)。**零 CoreKit 耦合**:缺翻译告警走 `push_warning` 而非 `CoreKit.log`,故可脱离门面独立实例化单测(同 `_settings=null` 意图)。
- 只改显式 `bind_theme` 的 `Theme.default_font`,不动 `ThemeDB` 等全局默认——副作用可控可回退。

## 用法示例

```gdscript
# 切语言(自动持久化,下次启动经 bind_settings 恢复)
CoreKit.i18n.set_locale("zh")

# 托管 tr:缺翻译时 debug 构建会去重告警,帮你发现漏翻
label.text = CoreKit.i18n.t("MENU_START")

# 字体回退:CJK 用专门字体,切语言时自动换整个 Theme 的默认字体
CoreKit.i18n.register_locale_font("zh", load("res://fonts/noto_sans_cjk.ttf"))
CoreKit.i18n.bind_theme(preload("res://ui/main_theme.tres"))

# 不用 bind_theme 的游戏,连信号自己换
CoreKit.i18n.locale_changed.connect(func(loc):
    my_label.add_theme_font_override("font", CoreKit.i18n.font_for_locale(loc)))

# 运行时追加(DLC / 热更翻译)
CoreKit.i18n.load_translations("res://dlc/translations")
```

## 注意事项

- **复数形式**(`translate_plural`)与**母语显示名**当前不做(用引擎英文名);有真实需求再加。
- **翻译资源**:`.po`/`.csv` 是编辑器导入期产物,运行时加载的是导入后的 `.translation`(或 `.tres`)。Godot 已在启动自动加载工程设置里配置的翻译;`load_translation*` 供额外/运行时追加。
- **字体不清**:切到未注册字体的 locale 时保留旧 `default_font`(不清)——CJK 字体通常含拉丁字形,保留无害。
- **持久化时机**:`set_locale` 落盘 section `"locale"`/键 `"current"`;`bind_settings` 在门面 `_ready` 恢复。切勿把 locale 存进 SaveManager 存档槽(那是跨存档偏好,归 Settings)。
```
