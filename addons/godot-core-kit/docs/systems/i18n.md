# i18n 本地化托管层(LocaleManager)

> `CoreKit.i18n` · `systems/locale_manager.gd` · 第 12 个子系统

## 职责

托管 Godot 全局 `TranslationServer`,给游戏一个单点本地化层:运行时切语言、持久化玩家选择、按 locale 换字体、开发期发现漏翻、运行时追加翻译。原生 `tr()` / `TranslationServer` 照旧可用,本层是增值托管而非替代。

## 公开 API

### 语言切换

| 成员 | 说明 |
|---|---|
| `set_locale(locale: String) -> void` | 切语言。空串 → 警告 no-op;与当前相同 → no-op(不重复落盘/发信号);否则切 `TranslationServer` + 持久化 + 换字体 + 发 `locale_changed`。 |
| `get_locale() -> String` | 当前 locale。 |
| `available_locales() -> PackedStringArray` | 有已加载翻译的 locale。 |
| `locale_display_name(locale) -> String` | 引擎英文显示名(如 `"en"` → `"English"`)。 |
| `signal locale_changed(locale: String)` | 每次成功切换后广播。 |

### 翻译访问

| 成员 | 说明 |
|---|---|
| `t(key, context := "") -> String` | 托管 `tr`:取当前 locale 译文;缺失(译文 == key)且 debug 构建时按 `locale\|key` 去重 `push_warning`(每键每语言仅一次)。 |
| `has_translation(key, context := "") -> bool` | 当前 locale 下是否有该 key 的翻译。 |

### 字体回退

| 成员 | 说明 |
|---|---|
| `register_locale_font(locale, font: Font) -> void` | 注册某 locale 的字体(null 忽略)。 |
| `font_for_locale(locale) -> Font` | 取注册字体,无 → null。 |
| `bind_theme(theme: Theme) -> void` | 绑定托管 Theme(null 清除);切 locale 时换其 `default_font`,绑定时若当前 locale 有字体立即应用。 |

### 运行时翻译加载

| 成员 | 说明 |
|---|---|
| `add_translation(translation: Translation) -> void` | 注册一个内存 `Translation`(null 忽略)。 |
| `load_translation(path) -> bool` | 加载一个 `.translation`/`.tres` 并注册;失败 → 警告 + false。 |
| `load_translations(dir) -> int` | 扫目录下 `*.translation`/`*.tres` 逐个加载,返回成功数。 |

### 门面接线

| 成员 | 说明 |
|---|---|
| `bind_settings(settings) -> void` | 门面在 `_ready` 注入;恢复上次持久化的 locale(section `"locale"`,键 `"current"`),`set_locale` 时写透。 |

## 依赖

- 单向依赖注入的 `Settings`(经 `bind_settings`,持久化 locale)。**零 CoreKit 耦合**:缺翻译告警走 `push_warning` 而非 `CoreKit.log`,故可脱离门面独立实例化单测(同 `_settings=null` 意图)。
- 只改显式 `bind_theme` 的 `Theme.default_font`,不动 `ThemeDB` 等全局默认——副作用可控可回退。

## 用法示例

```gdscript
# 切语言(自动持久化,下次启动经 bind_settings 恢复)
CoreKit.i18n.set_locale("zh")

# 托管 tr:缺翻译时 debug 构建会去重告警,帮你发现漏翻
label.text = CoreKit.i18n.t("MENU_START")

# 字体回退:CJK 用专门字体,切语言时自动换整个 Theme 的默认字体
CoreKit.i18n.register_locale_font("zh", load("res://fonts/noto_sans_cjk.ttf"))
CoreKit.i18n.bind_theme(preload("res://ui/main_theme.tres"))

# 不用 bind_theme 的游戏,连信号自己换
CoreKit.i18n.locale_changed.connect(func(loc):
    my_label.add_theme_font_override("font", CoreKit.i18n.font_for_locale(loc)))

# 运行时追加(DLC / 热更翻译)
CoreKit.i18n.load_translations("res://dlc/translations")
```

## 注意事项

- **复数形式**(`translate_plural`)与**母语显示名**当前不做(用引擎英文名);有真实需求再加。
- **翻译资源**:`.po`/`.csv` 是编辑器导入期产物,运行时加载的是导入后的 `.translation`(或 `.tres`)。Godot 已在启动自动加载工程设置里配置的翻译;`load_translation*` 供额外/运行时追加。
- **字体不清**:切到未注册字体的 locale 时保留旧 `default_font`(不清)——CJK 字体通常含拉丁字形,保留无害。
- **持久化时机**:`set_locale` 落盘 section `"locale"`/键 `"current"`;`bind_settings` 在门面 `_ready` 恢复。切勿把 locale 存进 SaveManager 存档槽(那是跨存档偏好,归 Settings)。
