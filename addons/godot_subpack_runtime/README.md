# Godot分包插件 Runtime

This addon is pure GDScript and is intended for exported games. It loads pack
files generated by the Godot分包插件 editor plugin without requiring the editor
GDExtension DLL at runtime.

```gdscript
const SUBPACK_RUNTIME_SCRIPT := preload("res://addons/godot_subpack_runtime/subpack_runtime.gd")

var runtime := SUBPACK_RUNTIME_SCRIPT.new()
runtime.load_manifest()
runtime.load_subpack_with_dependencies("extra_pack")
```

The runtime reads `subpack_manifest.json`, resolves dependencies, and mounts
packs through Godot's native `ProjectSettings.load_resource_pack()` API.
`load_manifest()` automatically checks the exported game directory
`subpacks/subpack_manifest.json`, the injected `res://subpacks` manifest, and
the editor demo output at `res://dist/subpacks`.

Remote packs use the same runtime and still avoid native code:

```gdscript
var runtime := SUBPACK_RUNTIME_SCRIPT.new()
await runtime.load_remote_manifest("https://cdn.example.com/subpacks/subpack_manifest.json")
await runtime.ensure_subpack_with_dependencies("level_02")
```

Remote downloads use `HTTPRequest`, cache verified `.bin`/`.pck` files under
`user://godot_subpack_cache`, and evict old cached files with an LRU budget from
the manifest. If a local pack exists, it is loaded before the remote cache or
network path.

In WeChat Mini Game exports, minigame manifests can provide
`wechat_subpackage_name` and `wechat_pack_path`. When running on Web with
`GODOTSDK.load_pack()` available, `ensure_subpack_with_dependencies()` loads the
matching WeChat subpackage first, then mounts the copied `.bin` through Godot.
Without those fields, the runtime defaults to
`/subpackages/<pack_name>/<relative_pack_file>`.
Each WeChat subpackage root must contain a `game.js`; the exporter/packaging
script generates an empty one, so game code should not maintain it manually.

For Godot Web export or browser-based demos, the remote host must allow CORS for
`GET` and `HEAD`. For Cloudflare R2, apply `scripts/r2_runtime_subpack_cors.json`
to the bucket before testing remote packs in a browser.

For visible loading diagnostics, call `drain_runtime_events()` after manifest or
pack operations. Events distinguish remote downloads, cache hits, SHA-256
verification, and final `ProjectSettings.load_resource_pack()` mounts.

Run `res://runtime_demo/subpack_demo.tscn` to verify the exported
`dist/subpacks` manifest and sample resources in a normal Godot scene.
