# godot-core-kit

## Agent skills

### Issue tracker

Issue 记在公司 GitLab(`origin`),用 `glab` 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认五个标签:`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context:根目录 `CONTEXT.md` + `docs/adr/`(按需由 `/domain-modeling` 创建)。See `docs/agents/domain.md`.
