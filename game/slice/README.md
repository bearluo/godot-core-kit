# 阶段 1 · 抛弃式手感切片

对照 `docs/vision/vision-one-pager.md` 的**核心瞬间**:

> 敌潮已入场 → 点格放塔 → 反馈 → 清波松一口气

## 怎么玩

```
godot --path . res://game/slice/feel_slice.tscn
```

1. 点「火塔/冰塔」选择
2. 点路径(中间列)两侧格子放下
3. 点「下一波」
4. 问自己:**像不像愿景纸上的感觉?**

## 结论(体验门,写于切片后)

- 点格 → 塔亮起(闪白 juice)有「落下」感。
- 波内持续输出 + 清波白闪,有短促松一口气。
- 漏怪扣核,激发「换站位再来」。
- **判定:核心瞬间成立 → 进入阶段 2 productionize。**
